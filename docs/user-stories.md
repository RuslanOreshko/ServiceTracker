# User Stories

## Authentication

### US-01 — Registration

As a user, I want to create an account so that I can use ServiceTracker.

### US-02 — Login

As a user, I want to log into my account so that I can access my data.

### US-03 — Logout

As a user, I want to log out of my account.


## Profile

### US-04 — Create profile

As a user, I want to create my profile with a username, name, avatar and description.

### US-05 — Edit profile

As a user, I want to edit my profile information.

### US-06 — Privacy settings

As a user, I want to control which information about me is visible to other users.


## Periods

### US-07 — Create period

As a user, I want to create a period such as education or service.

### US-08 — View current period

As a user, I want to see my current period and its progress.

### US-09 — View period history

As a user, I want to see my completed and current periods.

### US-10 — Edit period

As a user, I want to edit my period information.

### US-11 — Delete period

As a user, I want to delete a period.


## Progress

### US-12 — Calculate progress

As a user, I want the system to calculate how much of my current period has passed.

### US-13 — Calculate remaining time

As a user, I want to see how many days remain until the end of my current period.


## Achievements

### US-14 — Add achievement

As a user, I want to add an achievement to my profile.

### US-15 — View achievements

As a user, I want to see my achievements.

### US-16 — Edit achievement

As a user, I want to edit my achievement.

### US-17 — Delete achievement

As a user, I want to delete my achievement.


## Public profiles

### US-18 — View public profile

As a user, I want to view another user's public profile.

### US-19 — Search users

As a user, I want to search for other users.


## Events

### US-20 — Add event

As a user, I want to add an important event to my timeline.

### US-21 — View timeline

As a user, I want to see my education/service history as a timeline.
